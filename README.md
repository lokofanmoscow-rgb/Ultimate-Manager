# Ultimate Manager

Футбольный менеджер для Android (APK) в духе Football Manager: все лиги УЕФА (54 ассоциации, включая РПЛ), низшие дивизионы, национальные кубки и еврокубки, 3D-трансляция матчей.

**Готовый APK:** [`release/UltimateManager.apk`](release/UltimateManager.apk) — установите на Android 8.0+ (разрешите установку из неизвестных источников).

## Что есть в игре

- **Мир:** 54 ассоциации УЕФА, ~1250 клубов, ~35 000 игроков. До 5 дивизионов (Англия), реальные форматы чемпионатов: разделение на группы (Шотландия, Бельгия с делением очков, Австрия, Дания, Швейцария...), стыковые матчи, плей-офф за повышение, сезоны «весна–осень» (Норвегия, Швеция, Казахстан и др.).
- **Кубки:** национальные кубки с автоматической сеткой; **Кубок России — классический плей-офф** (Вторая лига → Первая лига с 1/32 → клубы РПЛ с 1/16, хозяева — клубы низшего дивизиона), Кубок английской лиги, суперкубки (в т. ч. «финал четырёх» в Испании и Италии).
- **Еврокубки (формат 2024+):** Лига чемпионов, Лига Европы, Лига конференций — квалификация (чемпионский/нечемпионский путь, переход проигравших в турниры ниже), общий этап 36 команд, стыковые матчи, плей-офф, финал. **РПЛ участвует в еврокубках**, коэффициенты УЕФА пересчитываются каждый сезон.
- **Игроки:** все характеристики как в FM (14 технических/вратарских, 14 ментальных, 8 физических + скрытые), уровень и потенциал, позиции, развитие и старение, травмы, мораль, форма, контракты. Ключевые игроки топ-клубов — реальные; **у всех 16 клубов РПЛ — актуальные составы сезона 2026/27** (состав лиг РПЛ и Первой лиги, итоговая таблица 2025/26 для еврокубкового посева). Остальные игроки сгенерированы.
- **Карьера:** имя, национальность, возраст, игровой опыт и лицензия тренера; выбор любого клуба.
- **Тактика:** 15 схем, роли и задачи (как в FM), командные инструкции, стандарты, сыгранность.
- **Трансферы и аренды:** поиск, шорт-лист, скауты, переговоры с клубом (встречные предложения, рассрочка) и с игроком (зарплата, срок, статус, бонусы, отступные), предложения ИИ-клубов за ваших игроков, трансферные окна.
- **Пресс-конференции:** до и после матчей — ответы влияют на мораль команды и отдельных игроков, доверие совета, ожидания (громкие заявления перед матчем повышают ставки), за критику судей можно получить штраф. Можно отправить ассистента.
- **Клуб:** финансы, персонал (найм/увольнение), тренировки, совет директоров (задачи, доверие, ультиматумы «наберите N очков в M матчах», увольнение, продление контракта), вакансии.
- **Матч:** 3D-трансляция с реальным движком (22 игрока, передачи, отборы, удары, стандарты), режимы «Полный матч / Расширенные / Ключевые моменты / Только текст», замены и тактика по ходу игры, перерыв с установкой, повторы голов, звук стадиона (гул трибун, реакция на моменты, свисток).
- **Сохранения:** 5 слотов + автосохранение.

## Сборка

```bash
cd web && npm install && npm run build      # собирает игру в android/app/src/main/assets/www
cd ../android && ./gradlew assembleRelease  # APK: android/app/build/outputs/apk/release/app-release.apk
```
Нужны Node.js 18+, JDK 17+ и Android SDK (platform 35, build-tools 35).

Проверка движка без интерфейса: `cd web && npx tsx scripts/simtest.ts` (сезон целиком) и `npx tsx scripts/enginetest.ts 20` (статистика матчевого движка).
